# Restaurant API

This is a RESTful API for managing restaurant operations, including authentication, user management, and menu handling.

## Features

- User authentication and authorization
- CRUD operations for users and menu items
- Error handling middleware
- Utility functions for API responses and error management

## Getting Started

### Prerequisites

- Node.js
- npm or yarn
- Prisma for database management

### Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd restaurant-api
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Set up your environment variables in the `.env` file.

### Running the Application

To start the server, run:
```
npm start
```

### API Documentation

Refer to the API documentation for details on available endpoints and usage.
